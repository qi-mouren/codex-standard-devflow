# 分析提示词（U1 提炼：文本通道 + 多模态通道）

## 使用方式

- **文本通道（默认，无需视觉模型）**：
  - 输入：种子 DESIGN.md（纯文本，1-2 份同品类）+ taste-skill/前端准则 + 项目源码/CSS 变量/设计 token 文件。
  - 第一遍：原则层（禁止数值）；第二遍：token 层（允许数值，从源码/CSS/DOM 证据提取）。
- **多模态通道（可选升级）**：
  - 输入：样本截图（一次 1 张或一组 5-10 张）；有录屏/帧序列时追加第三遍动效分析。
- 输出收敛为 `design-genome.md` + `design-dna.json`。

## 提示词正文（文本通道·第一遍：原则层，可直接复制）

> 你是一名 Principal Product Designer。基于以下种子设计文档与设计准则，提炼可以迁移到本项目 UI 的设计原则，不要复刻任何一家。
>
> 输入：种子 DESIGN.md 原文 + taste-skill/前端准则 + 项目产品定位（一句话）。
>
> 分析：
> 1. 产品定位与用户心理预期
> 2. 信息组织方式与空间关系
> 3. 视觉层级与色彩使用原则
> 4. 动效与交互反馈原则（种子有动效章节才写；没有则标 motion: unobserved）
> 5. 组件设计规律
>
> 禁止输出：px 尺寸、hex 颜色、CSS 代码。
>
> 输出：可迁移的设计原则（每条一句话、可判定），最后给出本项目的 3 个标志性特征 + 3 个必须避免的倾向。

## 提示词正文（文本通道·第二遍：token 层，可直接复制）

> 你是一名设计系统工程师。从给定的实现源码/CSS 变量/设计 token 文件（以及种子 DESIGN.md 的 token 章节）提取本项目 token 层：色板、字体与字号层级、间距、圆角、阴影、动效时长与缓动、核心组件样式。输出 design-dna.json，字段见 references/genome-schema.md。只填源码或种子中可观察到的值；取不到的值写 null 并注明"源码无此 token，来自种子"，禁止编造。

## 提示词正文（多模态通道·第一遍：原则分析，可直接复制）

> 你是一名 Principal Product Designer。你的任务不是复刻这个界面，而是提取这个 UI 背后的设计哲学。
>
> 分析：
> 1. 产品定位
> 2. 用户心理预期
> 3. 信息组织方式
> 4. 空间关系
> 5. 视觉层级
> 6. 色彩使用原则
> 7. 动效原则（有录屏/帧序列时：进入/退出、状态过渡、流式节奏、惯性、编排；仅静态截图时标注 motion: unobserved，禁止推断）
> 8. 交互反馈原则（有样本行为/状态序列时分析；仅静态截图时只写可观察到的状态表达）
> 9. 组件设计规律
>
> 禁止输出：px 尺寸、hex 颜色、CSS 代码。
>
> 输出：可以迁移到其他产品的设计原则（每条一句话、可判定）。最后给出：这个产品的 3 个标志性特征 + 3 个必须避免的倾向。

## 提示词正文（多模态通道·第二遍：token 提取，允许数值）

> 你是一名设计系统工程师。基于上一轮的设计原则分析，从同一批样本提取 token 层：色板主色/辅色/强调色/中性色阶、字体与字号层级、间距基准、圆角、阴影层级、动效时长与缓动、核心组件样式描述。输出 design-dna.json，字段见 references/genome-schema.md。只填样本中可观察到的值；观察不到的字段写 null 并说明，禁止编造。

## 提示词正文（多模态通道·第三遍：动效分析，给录屏或帧序列）

> 你是一名动效设计师。基于录屏/帧序列分析这个界面的动效系统，不要复刻，只提炼规律。
>
> 分析：
> 1. 进入/退出：哪些元素会动、从哪里来、编排顺序（stagger）是什么
> 2. 状态过渡：选中/悬停/展开/切换/错误等状态怎么过渡
> 3. 流式与加载：文本流式、骨架屏、加载反馈的节奏
> 4. 惯性/缓动：整体运动气质（弹、滑、稳），是否有明显突兀
> 5. 减少动态：是否尊重 prefers-reduced-motion，降级形态是什么
>
> 禁止输出：px 尺寸、hex 颜色、CSS 代码。
> 输出：可迁移的动效原则（每条一句话、可判定）+ 每阶段一句话描述。只凭静态截图能推断的内容标注"静态可推断"，其余标注"需录屏确认"。

## 多张样本收敛规则

- 每张样本先独立分析，再横向收敛（防丢失少数派规律）。
- 冲突时记 dominant pattern + variants，不强行合并。
- 收敛后只产出一份 genome + 一份 dna；多模态通道样本不足 10 张时先补样本再收敛；文本通道种子不足 2 份时补到 2 份跨产品种子。
- 动效规律只从录屏/帧序列收敛；静态截图样本的动效一律标 `motion: unobserved`。

## 文本通道规则（无视觉模型时的主通道）

- 以 awesome-design-md / oh-my-design 同品类 DESIGN.md + taste-skill/前端准则为底稿起草原则层。
- genome 顶部必须标注：`> 分析通道：文本（种子 + 准则），未经过截图分析。`
- token 层优先从源码/CSS 变量提取；取不到时用种子 token 并标注来源。
- 种子 DESIGN.md 若含动效章节（如 OpenAI/emil-design-eng 的时长与缓动规范），照抄进 token 层并标注来源；没有则 motion 章节标 unobserved。
- 文本通道产物是正式初稿（不是次等品），证据类型不同但同样可判定；进入 U3 前仍需人类确认。
