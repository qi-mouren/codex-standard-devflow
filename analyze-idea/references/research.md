# 调研与证据收集（research.md）

## 定位

调研是 S3 深度分析之前的**证据收集环节**：把"我觉得""我听说"变成"有来源的证据"。
六维度的每一个结论都必须能追溯到本环节的证据，或显式标注为"待验证假设"。

## 调研四步

1. 定问题：列出六维度分析必须回答的关键问题（从 03-deep-analysis 模板反推）
2. 选方法：每个问题至少选一种调研方法（见下）
3. 收集并记录：证据逐条记入 05-research-log.md，注明来源与可信度
4. 核查缺口：对照问题清单，标出没证据支撑的问题，转入"待验证假设"

## 四类调研方法

### 1. 桌面调研（先做，成本最低）

- 市场规模与趋势：行业报告、统计局/住建部门公开数据、上市平台财报披露
- 政策与合规：官方政策文件、主管部门公告、平台官方规则说明
- 竞争对手：公开产品、定价、门店/线上公开信息
- 注意事项：记录来源与发布时间；过时数据标注；区分"官方口径"与"自媒体说法"

### 2. 访谈调研（信息最真，优先一手）

- 对象：老客户、潜在客户、同行店东、门店经纪人、平台对接人
- 做法：半结构化问题，问"过去实际怎么做的"，少问"你未来会不会想要"
- 样本：至少 5-10 个有效样本；记录原话，不总结成自己的话
- 典型问题：
  - 你最近一次遇到这个问题是什么时候？当时怎么解决的？
  - 解决它花了多少钱/多少时间？
  - 如果有个方案帮你省一半功夫，你愿意付多少？
- 陷阱：只听满意客户（幸存者偏差）；只问"要不要"（确认偏误，白问）

### 3. 实地观察

- 门店流量：固定时段到访人数、咨询类型
- 竞品门店：位置、门面、人员、活动、主推业务
- 商圈环境：周边小区/人口/竞品密度
- 做法：计数、拍照、记录时间与样本量，样本量不足时注明"仅观察性证据"

### 4. 小成本实测（最强证据）

- 问卷：发到老客户群/门店到访者，N≥30 才有参考意义，注明样本量
- 预售/意向金：真有人掏钱，才是真需求
- 试点：挑一家店跑 2-4 周，用门店真实数据（线索数、转化率、成交额）说话
- 投放测试：小额广告/内容测试获客成本
- 注意：实测数据贵在真实，结果不好也是有效证据（避免"测试失败就重跑直到好看"）

## 证据分级

| 级别 | 定义 | 例子 |
|---|---|---|
| A 一手 | 自己访谈/实测/门店内部数据 | 老客户访谈、试点数据、成交记录 |
| B 二手官方 | 官方或权威来源 | 平台规则、政策文件、权威行业报告 |
| C 二手非官方 | 自媒体、传闻、转述 | 公众号文章、朋友说的、同行转述 |

- 同一结论尽量有 A 或 B 级证据支撑
- C 级证据只能作为"待核实线索"，不能作为结论依据

## 结束检查清单

- [ ] 六维度关键问题是否都有对应证据？
- [ ] 没有证据的问题是否已转入"待验证假设"？
- [ ] 每个证据是否记录了来源、日期、级别？
- [ ] 是否区分了"事实"与"推测"？
- [ ] 调研是否在可接受的时间/成本内停止（不无限调研）？

## 常见陷阱

1. 幸存者偏差：只听老客户，不听流失客户和拒绝过的人
2. 确认偏误：只找支持想法的证据
3. 传闻当事实：C 级证据当结论用
4. 调研上瘾：调研到决策点还在调研，用"再调研一下"逃避决定
5. 证据不过夜：访谈完不记录，凭记忆写报告
