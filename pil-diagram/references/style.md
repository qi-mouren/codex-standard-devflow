# PIL 手绘图表风格规范（style.md）

这是本 skill 的视觉语言唯一权威文字版。纯文本模型照此即可复刻，无需看图。

## 画布

- 逻辑尺寸默认 1560×1320；导出 SCALE=2 → 3120×2640
- 背景 `(250, 251, 253)`（极浅蓝灰）

## 字体

- 微软雅黑：常规 `C:\Windows\Fonts\msyh.ttc`，加粗 `C:\Windows\Fonts\msyhbd.ttc`
- 字号：正文 11–14px，小标题 15px，大标题 18–26px；卡片内副行 11–12.5px

## 色板（语义化，填浅底 + 深描边）

| 语义 | 描边 | 填充 |
|---|---|---|
| 需求锚定 / 警示 | 红 (231,76,60) | (253,236,234) |
| 设计 / 规划 | 蓝 (74,127,181) | (238,244,251) / (232,240,251) |
| 实现 / 集成 | 绿 (46,158,91) | (237,248,240) / (240,250,242) |
| 深绿大块（集成条） | 深绿 (46,125,91) | 白字 + 浅绿注释 (220,239,228) |
| 史诗/阶段 A | 橙 (230,126,34) | (253,243,231) |
| 史诗/阶段 B | 紫 (91,110,225) | (238,241,251) |
| 史诗/阶段 C | 青紫 (142,108,192) | (244,240,250) |
| 中性卡（底部说明） | 浅灰 (215,222,232) | 白 |

- 文字墨色 `(34,48,63)`，次要 `(102,114,127)`，线条灰 `(91,107,123)`
- 深色大块内文字用白色，副行用浅色（如 (200,210,223)）

## 卡片与连线

- 圆角矩形：radius=12（小 chip 6–8），描边 2px，浅底深边
- 连线：1.5px 细线 + 小三角箭头（d.polygon 画箭头，150° 张开）
- 虚线：等距线段（seg=7、gap=5，逻辑像素）
- 小标签 chip：白底 + 各史诗描边色 + 6px 圆角

## 布局纪律

1. 自上而下分段，每段一个小标题（`第一步 · …`、`第二步 · …`）
2. 顶部大标题 + 副标题 + 右上角图例（色块 + 语义文字）
3. 同一行卡片等高对齐；箭头末端落在目标卡片上边缘
4. 底部放"规则/说明"白卡，左右两块对称
5. 文字一律 `anchor="mm"`（图例用 `lm`），先算坐标再画

## 质检（必须做）

- 每条文字用 `canvas.fits(text, size, bold, max_w=卡片内宽)` 校验
- 溢出处理：先缩小字号，再扩卡片，最后才改布局
- 保存前整体过一遍所有 text 调用
